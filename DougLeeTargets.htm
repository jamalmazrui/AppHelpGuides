How to run it

  1. Unzip AppHelpGuides.zip into C:.
  2. Run getDougLeeTargetsHelp, or name apps to gather only those, for example getDougLeeTargetsHelp discord wireshark.
  3. Upload the AppHelpGuides folder’s new *Help.zip files and getDougLeeTargetsHelp.log.

Run it when no other visible-browser harvest is going. Dell Command Update and Twitch open Edge; the others open it only if a site refuses Python.
