About NVDA Coach

About this guide

Built from NVDA Coach 1.6.0, the add-on file nvdaCoach-1.6.0.nvda-addon. It needs NVDA 2024.1 or later, and was tested through NVDA 2026.1.1.

Each lesson below is laid out as the Coach presents it: one step at a time, with the keys the step expects, what the Coach says when it works, and the hints F2 gives. In the Coach itself, F1 repeats a step and F3 skips it.

During a Lesson

Each lesson guides you through a short series of steps. For steps that ask you to try an NVDA command, switch to another window and perform the action, then press NVDA+Shift+C to return to the Coach window and press Enter to confirm and continue. For steps with inline practice text, simply arrow down into the text area inside the Coach window and practice there directly. The following keys are always available during any lesson:

  • Enter: Advance to the next step.
  • F1: Repeat the current instruction.
  • F2: Get a hint for the current step. Press again to cycle through up to three hints per step.
  • F3: Skip the current step.
  • Escape: Stop the current lesson.
  • NVDA+Shift+C: Return to the Coach window from any other window.

For Instructors

Lessons are stored as plain JSON files in the add-on’s lessons folder. Each JSON file defines one lesson category with an ordered list of lessons, and each lesson is a list of steps. Steps can be informational (the student reads and presses Enter), gesture-based (the student performs the action themselves and confirms with Enter), or include inline practice text for in-window navigation drills. You can create new lesson categories by adding a new JSON file — see the included files as templates.

Getting Started

Press NVDA+Shift+C to open NVDA Coach. A persistent Coach window will appear on screen. The first time you open it, you will see an introduction and a lesson picker. Use the arrow keys to select a lesson and press Enter to begin.

The Coach window stays open throughout your session so you always have your instructions in front of you. Press NVDA+Shift+C at any time during a lesson to return to the Coach window if you have switched away to practice in another window.

Navigating Between Lessons

After completing a lesson, you can move to the next one without reopening the picker:

  • Ctrl+N: Move to the next lesson in the current chapter.
  • Ctrl+B: Go back to the previous lesson.
  • Ctrl+R: Restart the current lesson from the beginning.
  • NVDA+Shift+C: Open the lesson picker to jump to any lesson or chapter.

What is NVDA Coach?

NVDA Coach is an interactive training add-on that teaches you NVDA commands through short, hands-on drills. Instead of reading about commands in a manual, you practice them in real time with spoken feedback. The Coach guides you step by step and keeps you moving at your own pace from inside NVDA itself.

NVDA Coach is designed specifically for absolute beginners and people who are just starting out with screen readers. It was built by an assistive technology instructor who works with these students every day.

Chapter 1: Getting Started with NVDA

Lesson 1.01: Understanding Command Categories

Learn the essential NVDA commands every beginner needs. Each lesson is a short drill that takes about one to three minutes.

Step 1

Welcome to NVDA Coach. Before you practice any commands, it helps to understand something that most documentation glosses over: when you press a key on your keyboard, who is actually doing the work? There are three different layers that control keyboard commands on Windows, and knowing which layer a command belongs to will help you learn faster and make fewer mistakes. This lesson covers all three. Press Enter to continue.

Hints:

  • The three layers are: Windows itself, the application you are using, and your screen reader. Each handles different commands.
  • Windows commands work the same in every program. Application commands work only in the program they belong to. NVDA commands only announce information — they never change anything.
  • As you practice through this course, try guessing which category each new command belongs to before being told. This habit builds faster intuition.

Step 2

The first layer is Windows itself. Some commands belong entirely to the operating system. Cut, Copy, and Paste — Control+X, Control+C, and Control+V — are Windows commands. When any application lets you paste text, it is not the application doing the pasting; it is making a request to Windows to do it. Opening the Start Menu, switching between windows with Alt+Tab, and closing a window with Alt+F4 are also Windows commands. They work the same way in every program because Windows itself is in charge. Press Enter to continue.

Hints:

  • Control plus C copies, Control plus V pastes — these work in every Windows program because the operating system handles them, not the application.
  • Alt plus Tab switches between open windows. Alt plus F4 closes the current window. Both are Windows commands that work everywhere.
  • Windows commands are the most transferable skills you will learn — master them once and they work in every program you will ever use.

Step 3

The second layer is the application you are using. When you press Down Arrow in a word processor, you are telling the word processor to move your cursor to the next line. The application moves the cursor — that is a program command. Control+N in Microsoft Word opens a new document — that is Word’s command, not Windows. Your screen reader has nothing to do with moving that cursor. It simply reads aloud what the application already did. Press Enter to continue.

Hints:

  • Down Arrow in a word processor moves the cursor — the application does the work, and NVDA only reads aloud what happened.
  • The same key can mean different things in different applications. Control plus N opens a new document in Word but a new tab in a browser — because each application defines its own commands.
  • When something does not work as expected, remember: NVDA is only reading what the application shows. If the application is misbehaving, that is an application issue, not an NVDA issue.

Step 4

The third layer is your screen reader. NVDA commands are unique: they take no action in the application. They only inform. When you press NVDA+T, nothing changes in your document. The title bar does not move, no dialog opens, nothing is activated. NVDA simply announces what is already there — because sighted users can glance at the title bar any time, and you need a way to hear it. This distinction — take no action, only inform — is the heart of what makes screen reader commands different from all others. As you work through NVDA Coach, you will begin to recognize which layer each command belongs to without being told. Press Enter to begin your first lesson.

Hints:

  • NVDA commands always start with the NVDA modifier key — usually Insert or Caps Lock — and they never change anything on screen. They only speak information.
  • If you press NVDA plus T and nothing on screen changes, that is correct behavior. NVDA read the title bar aloud without modifying anything.
  • Think of NVDA commands as questions. NVDA plus T asks ‘what is the title of this window?’ NVDA answers in speech, and nothing changes.

Lesson 1.02: Meet Your NVDA Key

Step 1

Welcome to NVDA Coach! If you have an assistive technology instructor with you right now, this is a great moment to let them know you are starting. They can sit with you, help you find keys, and answer questions as you go. If you are working on your own, that is absolutely fine. NVDA Coach is designed to guide you independently, and you can do this. If you ever feel stuck, press F2 for a hint, F1 to hear the instruction again, or F3 to skip a step and come back to it later. In this first lesson, you will learn about the NVDA modifier key. This is the special key you hold while pressing other keys to send commands to NVDA. On most keyboards it is the Insert key. On many laptops it is Caps Lock. Press Enter to continue.

Hints:

  • On most desktop keyboards, the NVDA key is the Insert key. It is in the cluster of keys above the arrow keys, near Home, Delete, and Page Up.
  • On many laptops, Caps Lock serves as the NVDA key. It is on the far left of the keyboard, just above the left Shift key.
  • You can use both Insert and Caps Lock as NVDA keys at the same time. NVDA accepts either one, so you never have to choose between them.

Step 2

NVDA+N opens the NVDA menu — your hub for all of NVDA’s settings and features. Sighted users can click a menu with a mouse; NVDA+N is your equivalent. Try it now. Hold your NVDA key and press the letter N. You should hear NVDA open a menu and begin announcing items such as Preferences, Tools, and Help. Once you hear the menu open, press Escape to close it and come back here, then press Enter to continue.

Hints:

  • Hold the Insert or Caps Lock key down first, keep it held, then press the letter N. Both keys must be pressed together — not one at a time.
  • If the menu does not open, try again. Make sure you are holding the NVDA key before pressing N. A common mistake is releasing the NVDA key too early.
  • After the menu opens, press Escape to close it and return to where you were. Escape cancels menus and dialogs throughout all of Windows.

Step 3

Well done! You now know how to open and close the NVDA menu. NVDA+N opens the menu — it is your main hub for preferences, tools, and help. The Escape key closes menus and cancels actions, and you will use it constantly. These two shortcuts together give you full access to everything NVDA can do. Press Enter to finish this lesson.

Hints:

  • NVDA plus N is your master key for everything NVDA can do — settings, tools, help, and more. It is worth making it your first habit.
  • The Escape key closes menus and cancels dialogs without taking any action. It will never cause harm — when in doubt, press Escape.
  • Practice opening and closing the NVDA menu a few more times on your own. The muscle memory will build quickly.

Lesson 1.03: Read the Title Bar

Step 1

Every window has a title bar at the top that tells you which program you are in. Sighted users can glance at the title bar at any time. NVDA+T speaks the title bar aloud — your equivalent of that glance. Press Enter to continue.

Hints:

  • The title bar is the strip at the very top of every window. It usually shows the program name and sometimes the current document or page title.
  • NVDA plus T is a quick orientation command. Use it any time you are not sure which program is currently active.
  • Pressing NVDA plus T twice quickly spells out the title bar character by character — useful when the title contains an abbreviation you do not recognize.

Step 2

Try it now. Hold your NVDA key and press the letter T. You should hear NVDA read the title bar of the current window — something like the name of the program you are in right now. Whenever you are not sure which program you are looking at, NVDA+T will tell you immediately. It is one of the most useful commands you will ever learn. Press Enter here to continue.

Hints:

  • Hold your NVDA key — Insert or Caps Lock — and press the letter T. The T key is in the middle row of letters, between R and Y.
  • If NVDA reads something like ‘NVDA Coach — lesson window’, that is correct. It is reading the title of the currently active window.
  • Press NVDA plus T twice quickly to have NVDA spell out the title character by character. This is useful when the title is an unfamiliar word or abbreviation.

Step 3

Let’s do that one more time to build the habit. Hold your NVDA key and press T again. Listen as NVDA reads the title bar aloud. Repetition is how keyboard commands become automatic — the more you practice, the faster each command becomes second nature. Press Enter here when you are ready to continue.

Hints:

  • This time, try switching to a different open window first with Alt plus Tab, then press NVDA plus T to hear that window’s title.
  • NVDA plus T is especially useful after switching windows with Alt plus Tab, since you cannot always tell by ear which program you just landed in.
  • Hold NVDA, press T, then release both. You should hear the title spoken immediately.

Lesson 1.04: Read the Time

Step 1

Sighted users can glance at the clock in the corner of the screen. NVDA+F12 speaks the current time without you having to navigate anywhere. NVDA can tell you the current time and date without leaving what you are doing. Press Enter to continue.

Hints:

  • F12 is the last function key on the top row of your keyboard, on the far right end of the row labeled F1 through F12.
  • Pressing NVDA plus F12 twice quickly reads the current date instead of the time — a handy way to check both without opening any program.
  • Function keys run across the very top of the keyboard. F12 is at the far right end of that row, often next to a Print Screen or Scroll Lock key.

Step 2

Try it now. Hold your NVDA key and press F12 — the last function key on the top row of your keyboard, usually on the far right. You should hear NVDA announce the current time. Quick tip: if you press NVDA+F12 twice in rapid succession, NVDA reads the date instead of the time. Give both a try if you like, then press Enter here to continue.

Hints:

  • F12 is the last key in the row of function keys across the top of the keyboard. Hold your NVDA key and press F12.
  • If you are not sure you pressed the right key, use Input Help: press NVDA plus 1 to turn it on, press the key you want to test, listen to the description, then press NVDA plus 1 again to turn it off.
  • Press NVDA plus F12 twice in quick succession to hear the full date. The first press gives the time; the second rapid press gives the date.

Lesson 1.05: Check Your Battery Status

Step 1

If you are using a laptop, NVDA can tell you your battery level and whether the charger is connected — without touching the mouse or navigating to the taskbar. Press NVDA+Shift+B to have NVDA announce the current battery status. NVDA will say something like “Battery: 74 percent, not charging” or “Battery: 91 percent, charging”. This command only works on laptops and tablets that have a battery. On a desktop computer, NVDA may say nothing or report no battery found. Press Enter to continue.

Hints:

  • NVDA plus Shift plus B is an NVDA command that reads the battery level instantly — no navigation required.
  • The report includes the percentage remaining and whether the power adapter is connected. “Not charging” means the charger is unplugged or the battery is full.
  • If you do not hear anything, your computer may be a desktop with no battery, or the battery driver may not be reporting status. This is normal on most desktop PCs.

Step 2

Try it now. Hold your NVDA key and Shift, then press B. Listen for NVDA to announce the battery level. If you are on a laptop, you will hear the percentage and charging state. If you are on a desktop, NVDA may report no battery. Press Enter when you are ready to continue.

Hints:

  • Hold NVDA and Shift together, then press B. NVDA will announce the battery status immediately.
  • On a laptop: listen for the percentage and whether the charger is plugged in. On a desktop: NVDA may say nothing or report no battery found.
  • This is a quick status check — it does not open any window or dialog. You can use it any time without interrupting what you are doing.

Lesson 1.06: Stop NVDA from Talking

Step 1

Sometimes NVDA talks too much or you want it to stop mid sentence. The Control key by itself immediately silences speech. This is called stopping speech, and it works in Narrator, JAWS, and VoiceOver as well — it is a universal screen reader convention. Press Enter to continue.

Hints:

  • The Control key is in the bottom left corner of your keyboard. Most keyboards also have a second Control key in the bottom right corner. Either one silences NVDA.
  • A single tap of Control stops NVDA speech instantly. You do not need to hold it or combine it with any other key.
  • Control stops speech completely and cannot resume. Shift, which you will learn next, pauses and can be pressed again to resume from where NVDA left off.

Step 2

There is also a second option: the Shift key. Pressing Shift pauses NVDA’s speech mid-sentence. Press Shift again and NVDA resumes reading right where it left off. This pause-and-resume behavior is specific to NVDA. It is useful when you need a brief moment to focus — for example, reading a phone number from a document while you dial it. Press Shift once to pause, then press Shift again to continue. Control stops completely. Shift pauses and resumes. Both are worth knowing. Press Enter to continue.

Hints:

  • The Shift key is the wide key just above the Control key on either side of the keyboard. A single press pauses NVDA; pressing it again resumes from exactly where it left off.
  • Use Shift to pause when you need a moment to act — for example, NVDA is reading a phone number and you need to dial it. Pause with Shift, dial, then Shift again to continue.
  • Control stops completely with no resuming. Shift pauses and resumes. Both are single key presses with no modifiers needed.

Step 3

A note on practicing these keys: pressing Control or Shift during an active lesson would interfere with the lesson itself, so reliable in-lesson practice is not possible here. Instead, build the habit naturally. The next time NVDA reads something too long or too fast, reach for Control to stop it. When you need a moment mid-reading, try Shift to pause and resume. You will discover both reflexes quickly in real use. Press Enter to finish this lesson.

Hints:

  • Try this in any application after this lesson: open a long email or web page, let NVDA begin reading something, then press Control to stop it cold. The reflex builds quickly with daily use.
  • These keys are completely safe to press at any time. They only affect NVDA’s speech output and have no effect on the application you are using.
  • You will develop these reflexes naturally through daily use. The next time NVDA reads something too long, reach for Control — and it will become automatic.

Lesson 1.07: Find Out Where You Are

Step 1

Sighted users can see which control is highlighted on screen. NVDA+Tab speaks the name, type, and state of whatever control you are currently focused on — your equivalent of that visual glance. Press Enter to continue.

Hints:

  • NVDA plus Tab reads the currently focused control — its name, type (button, checkbox, edit field), and state (checked, pressed, etc.).
  • Note the difference: Tab alone moves you to the next control. NVDA plus Tab reads the current control without moving anywhere.
  • This command is most useful when you land somewhere unexpected and need to figure out where you are before doing anything else.

Step 2

A practice login form is about to open in a separate window. When it appears, press Alt+Tab to switch to it. Tab to different controls and press NVDA+Tab on each one to hear NVDA describe it. When you are done, press Alt+Tab to return here, then press NVDA+Shift+C to bring the Coach window forward, and press Enter to continue. Ready? Press Enter now to open the practice form.

Hints:

  • Press Alt plus Tab to switch to the practice window after it opens. Hold Alt and press Tab once to move to the next open window.
  • If you switch to the wrong window, keep holding Alt and press Tab again to cycle through all open windows until you hear the practice form.
  • The practice form has a username field, a password field, a checkbox, and buttons. Tab to each one and press NVDA plus Tab to hear how NVDA describes each type of control.

Step 3

Now in the practice window, Tab to any control in the login form, then press NVDA+Tab. NVDA will announce the name, type, and state of whatever control you are focused on. For example it might say ‘Username edit’ or ‘Sign in button.’ Try it on several different controls — text fields, the checkbox, and each button — to hear how NVDA describes each type. When you are done exploring, press NVDA+Shift+C to return here, then press Enter to continue.

Hints:

  • Hold your NVDA key and press Tab. This is different from Tab alone — Tab alone moves focus, but NVDA plus Tab only reads the current control without moving.
  • Try NVDA plus Tab on several different control types. A text field sounds different from a button, which sounds different from a checkbox.
  • When you are done, press NVDA plus Shift plus C to bring the Coach window forward, then press Enter to continue.

Lesson 1.08: Move Between Controls with Tab

Step 1

In dialog boxes, settings windows, and forms, you press the Tab key to move forward between controls like buttons, checkboxes, and text fields. Shift+Tab moves you backwards. This is the same in every Windows program — learning it here means you can use it everywhere. You will use Tab and Shift+Tab throughout this course, including inside the NVDA Settings dialog in the Customizing NVDA chapter. Press Enter to continue.

Hints:

  • The Tab key is on the far left side of the keyboard, just above Caps Lock. It often has a symbol with two arrows pointing in opposite directions.
  • Shift plus Tab moves backwards through controls — opposite direction from Tab alone. Together they let you move freely through any form or dialog.
  • Tab and Shift plus Tab work identically in every Windows dialog, form, and settings window. Master them here and you can use them in any program.

Step 2

A practice form is about to open in a separate window. When it appears, press Alt+Tab to switch to it. Press Tab to move forward through the controls. When you are done, press Alt+Tab to return here, press NVDA+Shift+C to bring the Coach window forward, and press Enter to continue. Ready? Press Enter now to open the practice form.

Hints:

  • Press Alt plus Tab to switch to the practice form after it opens. Hold Alt and tap Tab once.
  • Press NVDA plus Shift plus C at any time to bring the Coach window back to the front.
  • The practice form has several controls — text fields, checkboxes, and buttons. Tab all the way through the form before returning.

Step 3

Switch to the practice form by pressing Alt+Tab. Once you are there, press Tab to move to the next control. NVDA will announce the name and type of each control as you land on it. Keep pressing Tab to move through the whole form. When you are ready, press NVDA+Shift+C to come back here, then press Enter to continue.

Keys: Tab.

When it works: You moved to the next control. NVDA announced what you landed on.

Hints:

  • The Tab key is on the far left of the keyboard, just above Caps Lock. Press it by itself — no modifier key needed.
  • Each press of Tab moves to the next control and NVDA announces its name and type. Listen for words like ‘button’, ‘edit’, or ‘checkbox’.
  • If you Tab past the last control in the form, focus wraps back to the first control. This is normal — you can keep pressing Tab to cycle through indefinitely.

Step 4

Now in the practice form, press Shift+Tab to move back to the previous control. Hold Shift and press Tab. NVDA will announce the control you return to. Tab goes forward, Shift+Tab goes back. Press NVDA+Shift+C to return here when ready, then press Enter to continue.

Keys: Shift+Tab.

When it works: You moved backwards. Tab goes forward, Shift+Tab goes back. These two keys will carry you through most dialog boxes and forms.

Hints:

  • Hold Shift first, then press Tab while keeping Shift held. Shift is the wide key above the left Control key.
  • Shift plus Tab always moves backwards — the exact opposite of Tab alone. Use it whenever you overshoot a control and need to back up.
  • You never have to start over from the beginning of a form. If you go too far, Shift plus Tab brings you right back.

Lesson 1.09: Activate Buttons and Controls

Step 1

Once you have Tabbed to a button or control, you need to activate it. Enter activates buttons and default actions. Space toggles checkboxes on and off. These keys work the same way in every Windows program. Press Enter to continue.

Hints:

  • Enter activates buttons. Space toggles checkboxes on and off. These two keys handle nearly all activation tasks in Windows dialogs.
  • After pressing Space on a checkbox, NVDA announces ‘checked’ or ‘unchecked’ to confirm the new state.
  • For radio buttons, use the Up and Down Arrow keys to move between options rather than Space or Enter.

Step 2

A practice window with checkboxes and buttons is about to open. When it appears, press Alt+Tab to switch to it. When you are done, press Alt+Tab to return here, press NVDA+Shift+C to bring the Coach window forward, and press Enter to continue. Ready? Press Enter now to open the practice window.

Hints:

  • Press Alt plus Tab to switch to the practice window after it opens.
  • The practice window has checkboxes and buttons. Tab to each one and listen to how NVDA announces the control type so you know which key to use.
  • NVDA announces button names and checkbox labels as you Tab to them. Buttons get Enter; checkboxes get Space.

Step 3

Switch to the practice window with Alt+Tab. Tab to one of the checkboxes labeled ‘Enable screen reader tips’ or ‘Show practice hints during lessons’, then press the Space bar to check or uncheck it. NVDA will announce whether the box is now checked or unchecked. When you are done, press NVDA+Shift+C to return here, then press Enter to continue.

Keys: Space.

When it works: Space bar pressed. Space is used to check or uncheck checkboxes and to activate some buttons.

Hints:

Lesson 5.01: What Is Object Navigation?

Learn how to explore and interact with controls that cannot be reached with the Tab key, using NVDA’s object navigation commands.

Step 1

Welcome to the Object Navigation chapter. Most of what you have learned so far uses the Tab key and arrow keys to move through a screen. But some programs — especially older desktop applications — have controls that Tab cannot reach. NVDA has a separate system for exploring these called object navigation. It lets you move through every element on the screen, whether or not it accepts keyboard focus. Before you begin: maximize your current application window if it is not already full screen. Press Windows+Up Arrow (Windows command) to maximize. This ensures all objects are visible and accessible to the navigator. Press Enter to continue.

Hints:

  • Object navigation is separate from Tab navigation. Tab only reaches controls designed to accept keyboard focus. Object navigation reaches everything on screen.
  • Older desktop applications — like some media players, custom toolbars, and accessibility tools — often have controls that do not respond to Tab. Object navigation is how you reach them.
  • To maximize your window before exploring, press Windows+Up Arrow. A maximized window ensures no objects are hidden off-screen or clipped.

Step 2

NVDA thinks of the screen as a tree of objects — picture a pyramid. At the top is the application window. The level below it contains panels, toolbars, and menus. The level below that contains the individual controls: buttons, text fields, and checkboxes. Each object may contain more objects at the level below it. Object navigation lets you move through this pyramid in any direction: across to the next object at the same level, up one level to the container, or down one level to the first object inside. Press Enter to continue.

Hints:

  • Think of the pyramid like a building. The whole building is the application. Each floor is a level. Each room on a floor is a panel or toolbar. Each item in a room is an individual control.
  • Every element on screen — a toolbar button, a status bar, a progress indicator — lives somewhere in this pyramid, even if Tab cannot reach it.
  • Object navigation is most useful in programs that have non-standard controls — custom toolbars, status bars, notification areas, and embedded controls.

Step 3

There are two keyboard layouts in NVDA: desktop and laptop. Desktop layout uses the numeric keypad on the right side of a full-size keyboard. Laptop layout uses combinations of NVDA plus letter or symbol keys so you do not need a numpad. All object navigation commands in this chapter will show both layouts. If you are not sure which layout you are using, open the NVDA menu with NVDA+N (NVDA command), go to Preferences, then Settings, then Keyboard, and listen for the layout setting. Press Enter to continue.

Hints:

  • Desktop layout uses numpad keys for object navigation. Laptop layout adds Shift to many arrow key combinations. All commands in this chapter list both.
  • If you are not sure which layout you are using, press NVDA+1 (NVDA command) to turn on Input Help, then press one of the object navigation keys to hear which layout NVDA expects. Then press NVDA+1 again to turn Input Help off.
  • You can change your keyboard layout at any time in NVDA Settings under the Keyboard category. The Customizing NVDA chapter covers this in detail.

Step 1

Lesson 6.04: Control Audio Ducking

Step 1

Audio ducking controls what happens to other sounds on your computer when NVDA speaks. When ducking is active, NVDA automatically lowers the volume of music, videos, or other audio while it is talking, then restores the volume when it finishes. This prevents NVDA speech from competing with other sounds. Press NVDA+Shift+D to cycle through the three ducking modes: No ducking, Duck when outputting speech and sounds, and Always duck. This command only works when NVDA has been installed on the computer: on a portable copy it does nothing, and that is expected rather than a fault with your sound card. Press Enter to continue.

Hints:

  • NVDA plus Shift plus D is an NVDA command. Each press cycles to the next ducking mode and NVDA announces the new mode by name.
  • The three modes are: No ducking (other audio plays at full volume), Duck when outputting speech and sounds (audio lowers only while NVDA is talking), and Always duck (audio stays lowered even when NVDA is silent).
  • Audio ducking is only available when NVDA has been installed. If you are running NVDA from a USB drive, NVDA+Shift+D does nothing at all. On an installed copy, if you hear no difference between modes, your audio driver may not support ducking.

Step 2

Try it now. Open a music player or video and let it play. Then press NVDA+Shift+D once and listen: if ducking is now active, you will notice the music drop in volume when NVDA speaks. Press NVDA+Shift+D again to hear NVDA announce the next mode. Cycle through all three to find the setting that works best for your workflow. Press Enter here when you are ready to continue.

Hints:

  • Hold NVDA and Shift together, then press D. NVDA announces the new ducking mode immediately.
  • Start with music or a video playing so you can clearly hear whether ducking is working. The volume drop should be noticeable when NVDA begins to speak.
  • If no mode changes anything, check first whether this is a portable copy of NVDA, because ducking needs an installed copy. On an installed copy it is usually the audio driver, which is common with some USB headsets and virtual audio devices.

Step 3

Your preferred ducking mode is saved automatically and will be active every time NVDA starts. Most users prefer Duck when outputting speech and sounds — it keeps audio at full volume when NVDA is quiet and only lowers it when speech begins, so you can follow both the audio content and NVDA announcements without one drowning out the other. Press Enter to finish this lesson and complete the Customizing NVDA chapter.

Hints:

  • Duck when outputting speech and sounds is the most popular mode — audio plays normally when NVDA is quiet and drops only when NVDA speaks.
  • Always Duck is useful if you find audio distracting even between NVDA announcements, such as when using NVDA in a noisy or media-heavy environment.
  • No Ducking is the default. If you prefer all audio at full volume at all times and want to hear NVDA and other sounds simultaneously at full level, this mode leaves everything unchanged.
